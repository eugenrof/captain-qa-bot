ⓘ Where do I get a Gemini API key?

Create one in Google AI Studio → API Keys.

  1. Open Google AI Studio
  2. Create an API key
  3. Copy it
  4. Paste it above
  5. Click Validate & Save

Your API key is stored locally in this browser and is never committed to the project.
